# 📁 Flutter File Manager

A modern, fast, and elegant Material Design 3 File Manager application built with Flutter for Android and Web.

## 🚀 Features

- **Material 3 Interface**: Expressive Material You dynamic themes, navigation bar with pill indicators, and fluid animations.
- **Storage Overview**: Visual breakdown of internal storage usage (Images, Videos, Audio, Documents, Apps, Archives, Code).
- **Storage Cleaner**: Instant one-tap cache sweeper and duplicate file finder.
- **Encrypted Safe Folder**: Secure 4-digit PIN protected locker for confidential files.
- **In-App Media & Document Preview**: Built-in viewers for pictures, text files, and markdown documents.
- **Search & Sort**: Real-time filtering by keyword and sorting by Name, Date, Size, and Extension.

```bash

cd flutter-file-manager-apk
flutter pub get
flutter run
```

To build a release APK:

